Sử dụng AI để tìm nguyên nhân và khắc phục lỗi CSS không hiển thị

Đưa mã nguồn website lên GitHub
Viết AI_Log
Sử dụng GitHub Copilot để hỗ trợ tìm và sửa lỗi CSS không hiển thị trên website
